05 · Datos que requieren validación manual

HubSpot ya alimenta automáticamente los indicadores principales mediante la Edge Function. Este formulario solo actualiza KPIs manuales y notas.

Actualización de HubSpot: ejecuta sync-hubspot-awki desde Supabase para refrescar los indicadores automáticos; después pulsa «Actualizar datos» aquí. Este botón solo vuelve a consultar Supabase, no ejecuta la función. No vuelvas a introducir manualmente contactos, empresas o actividad.
Mantén denominadores comparables. Usa secuencias completas únicamente cuando se hayan ejecutado todos los pasos aprobados (emails, llamadas u otros). Una casilla vacía significa dato no disponible.

07 · Criterios de interpretación

El diagnóstico de secuencias e ICP del 23/10 es histórico y no sustituye un cierre mensual. La visión ejecutiva utiliza el último corte disponible. Los cortes automáticos son fotografías acumuladas, salvo que una métrica esté definida expresamente para un período o cohorte. Sent no certifica entrega; apertura no significa interés; Completed de una llamada no implica conversación; una reunión sin objeto CRM puede existir. Este dashboard lee los cortes y la actividad mensual que las Edge Functions sincronizan desde HubSpot hacia Supabase; cada actualización se ejecuta por separado.
